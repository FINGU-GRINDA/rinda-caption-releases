# Rinda 강연 자막 — 배포본

## 요약

Rinda 강연 자막(rinda-caption)은 발표 화면 위에 마이크로 들은 말을 실시간 번역 자막으로 겹쳐 그리는 데스크톱 앱이다. 이 저장소는 소스 없이 설치파일(Windows `.exe`, macOS Apple Silicon `.app.tar.gz`)과 자동 업데이트 정보(`latest.json`, 서명 `.sig`)만 GitHub Releases 로 배포하는 공개 배포 전용 저장소다. 앱이 인증 없이 업데이트를 확인해야 해서 공개로 둔다. 2026-08 기준 최신 배포는 v0.1.6 이다.

발표 화면 **위에 직접** 실시간 번역 자막을 그리는 데스크톱 앱입니다.

> **이 저장소에는 소스 코드가 없습니다.** 설치파일과 자동 업데이트 정보(`latest.json`)만
> 올라옵니다. 앱이 업데이트를 확인하려면 이 주소가 인증 없이 열려 있어야 해서 공개로 둡니다.

## 내려받기

[**Releases**](../../releases/latest) 에서 받으세요.

| 운영체제 | 파일 |
|---|---|
| Windows | `..._x64-setup.exe` |
| macOS (Apple Silicon) | `..._aarch64.app.tar.gz` (압축을 풀어 나온 앱을 응용 프로그램 폴더로 옮김) |

`.sig` 파일과 `latest.json` 은 자동 업데이트용이라 내려받지 않아도 됩니다.

## 설치할 때 나오는 경고

아직 OS 코드서명을 하지 않아 처음 실행할 때 경고가 뜹니다.

- **Windows** — "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- **macOS** — "확인되지 않은 개발자" 경고가 뜨면 앱을 **우클릭 → 열기**로 실행하세요.

처음 한 번만 하면 그다음부터는 바로 열립니다.

## 마이크 권한

자막은 마이크로 들어온 말을 옮기므로 마이크 접근을 한 번 허용해야 합니다.
macOS 는 **시스템 설정 → 개인정보 보호 및 보안 → 마이크** 에서 켜 주세요.

## 자동 업데이트

앱을 켤 때 새 버전이 있는지 조용히 확인하고, 있으면 창 아래에 버튼으로 알려 줍니다.
**자막이 나가는 중에는 업데이트가 설치되지 않습니다** — 설치 과정에서 앱이 종료되기 때문에,
발표 도중 자막이 끊기지 않도록 막아 둔 것입니다. 자막을 끄고 눌러 주세요.
